# Ориентир

**Ориентир** — справочный веб-помощник для врачей Детской республиканской клинической больницы (ДРКБ). Врач вводит возраст ребёнка, пол и результаты лабораторных анализов вместе с референсными интервалами из бланка. Сервис сравнивает значения с интервалами, отмечает показатели ниже, выше или в пределах, показывает справочные пояснения и предлагает врачу рекомендации для рассмотрения: контроль или пересдачу анализа и консультацию специалиста профильного направления. Рекомендации формируются по утверждённым правилам, а YandexGPT оформляет текст.

## Статус

**Учебный прототип.** Работает на вымышленных (синтетических) данных, рекомендации помечены как учебные и не предназначены для клинического применения. Внедрение в больнице возможно только после согласований (статус медицинского изделия, внешний ИИ-сервис, правила от медицинского эксперта). Срок прототипа: 1 декабря. Работа выполняется в рамках задания «Применение ИИ в обработке медицинских данных».

## Принципы

- **Без персональных данных.** Нет имён, номеров карт, дат и свободного текста: только возраст, пол, название показателя и числа.
- **Ничего не сохраняется.** Введённые данные не записываются ни в базу, ни в файлы, ни в журналы. Закрыл страницу, и данных нет.
- **Решение за врачом.** Рекомендации даются «для рассмотрения врачом». Сервис не ставит диагноз, не назначает лечение и не делает выводов по сочетанию показателей.
- **Рекомендации по правилам.** Они берутся из правил справочника и срабатывают в коде. ИИ не придумывает их сам.

## Технологии (предлагается)

Python и Django, PostgreSQL (справочник, правила, настройки), YandexGPT, размещение в Yandex Cloud.

## О названии

Проект раньше назывался «Росток» и был сервисом для родителей. Название «Ориентир» выбрано после смены направления: теперь это помощник врача. Репозиторий пока называется Rostok.
