# Запуск и размещение «Ориентира»

Приложение: Python и Flask (`app/`), справочник в `spravochnik.json`. База данных не нужна, данные не сохраняются.

## 1. Запуск у себя

```
pip install -r requirements.txt
cd app
python main.py        # откроется http://127.0.0.1:8000
```

Без ключей YandexGPT приложение работает: вместо ИИ показываются тексты справочника.

## 2. Подключение YandexGPT

1. В консоли Yandex Cloud создайте сервисный аккаунт с ролью `ai.languageModels.user`.
2. Создайте для него API-ключ (область действия `yc.ai.languageModels.execute`). Ключ показывается один раз, сохраните его.
3. Возьмите идентификатор каталога (folder ID) каталога, где создан аккаунт.
4. Передайте приложению переменные окружения `YANDEX_API_KEY` и `YANDEX_FOLDER_ID` (при необходимости `YANDEX_MODEL`).

Ключ не вставляйте в код и не отправляйте в чат или репозиторий.

## 3. Размещение в Yandex Cloud (вариант с контейнером)

1. Соберите образ: `docker build -t orientir .`
2. Загрузите его в Container Registry.
3. Создайте Serverless Container (или Compute Cloud с Docker) из этого образа, порт 8080.
4. Задайте переменные `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`. Для Serverless Container лучше хранить ключ в Lockbox.
5. Сделайте контейнер публичным для демонстрации (или оставьте доступ по ссылке только для команды).

Как это сделали коллеги по проекту, можно спросить у них: схема размещения будет такой же.

## 4. Проверка
- `/health` отвечает `ok`.
- Демо-кнопки на главной подставляют вымышленные примеры.
