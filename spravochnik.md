## 3. Что нужно проверить до реального использования

- Поле «специалист» (гематолог, педиатр, эндокринолог) выбрано как учебное допущение. Его должен подтвердить врач-эксперт.
- Пояснения для показателей 2–8 написаны по общеизвестным сведениям, без привязки к конкретному документу. Для утверждённой версии каждому нужен источник из российских документов: клинические рекомендации Минздрава РФ (рубрикатор cr.minzdrav.gov.ru), национальные руководства, справочные материалы Федерации лабораторной медицины.
- Для гемоглобина источниками указаны российские клинические рекомендации «Железодефицитная анемия» (2024, взрослые и дети; разработчики включают Национальное общество детских гематологов и онкологов) и руководство ВОЗ по пороговым значениям гемоглобина (2024). Пороги из этих документов в справочник не копировались.
- Для ферритина источником указано руководство ВОЗ по использованию ферритина для оценки статуса железа (2020). ВОЗ не публикует детские референсные интервалы для лейкоцитов, тромбоцитов, СОЭ, глюкозы и СРБ в виде общих значений, поэтому для них источник остаётся прежним (составлено автором) до сверки с российскими документами. Ссылки на ВОЗ взяты из поиска, сами документы целиком не читались.
- Свободных текстов и значений о конкретных пациентах в справочнике нет.
